# Sistema-notas-escolares-

Sobre:
O Sistema de Notas Escolares é um projeto que tem como finalidade facilitar o gerenciamento de informações acadêmicas, permitindo o cadastro de alunos, professores, disciplinas, avaliações e notas.

O sistema busca centralizar as informações escolares em uma única plataforma, tornando o acompanhamento do desempenho dos estudantes mais organizado e eficiente.

Objetivo
Desenvolver um sistema web que permita registrar notas, calcular médias automaticamente e consultar o desempenho dos alunos.

Requisitos funcionais

Os requisitos funcionais descrevem o que o sistema deverá fazer.

RF01: Permitir login dos usuários.

RF02: Cadastrar, editar e excluir alunos.

RF03: Cadastrar, editar e excluir professores.

RF04: Cadastrar disciplinas.

RF05: Cadastrar turmas.

RF06: Registrar avaliações.

RF07: Lançar notas dos alunos.

RF08: Calcular médias automaticamente.

RF09: Identificar alunos aprovados e em recuperação.

RF10: Permitir consultar boletins escolares.

RF11: Gerar relatórios de notas.

Requisitos não funcionais

Os requisitos não funcionais descrevem como o sistema deverá funcionar.

RNF01: O sistema deverá ter uma interface simples e fácil de utilizar.

RNF02: O sistema deverá proteger os dados dos usuários.

RNF03: O acesso deverá ser controlado por usuário e senha.

RNF04: O sistema deverá funcionar nos principais navegadores.

RNF05: O banco de dados deverá armazenar as informações com segurança.

RNF06: O sistema deverá apresentar respostas em tempo adequado.

Regras de avaliação

A média será calculada com quatro notas de pesos iguais.

Fórmula:  Média = (N1 + N2 + N3 + N4) / 4

Usuários do sistema

Administrador: gerencia o sistema.

Professor: registra e consulta notas.

Aluno: consulta notas e boletins.

Responsável: acompanha o desempenho do aluno.
